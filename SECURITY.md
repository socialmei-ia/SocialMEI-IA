# Segurança

O SocialMEI.IA é um projeto acadêmico em desenvolvimento.

## Nunca publique

- arquivos `.env`;
- chaves `.pem`;
- senhas;
- tokens;
- chaves de API;
- credenciais do n8n;
- backups ou dumps de banco.

Use somente placeholders no `.env.example`.

Se encontrar uma credencial exposta, não abra uma issue pública contendo o segredo. Avise os responsáveis pelo projeto por um canal privado e revogue a credencial afetada.
