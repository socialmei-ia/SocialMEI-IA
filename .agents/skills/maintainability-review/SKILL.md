---
name: maintainability-review
description: Simplify SocialMEI code without changing behavior, removing unnecessary verbosity and making future maintenance easier.
---

Prefer direct names, focused functions, clear early returns, existing patterns, concise comments and safe removal of dead/redundant code.
Fix CSS at the source rather than stacking final overrides.

Avoid framework migration, speculative abstraction, mass contract renaming, obvious comments, technical emojis and artificial imperfections intended to look human.

Preserve behavior and run relevant tests.
