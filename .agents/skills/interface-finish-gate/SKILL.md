---
name: interface-finish-gate
description: Run the final SocialMEI product-quality gate after an interface implementation and before approval or merge.
---

Check:
- primary task/action is visually obvious;
- hierarchy and density fit the specific workflow;
- no generic AI-style card/glow/gradient/glass decoration without purpose;
- no fake metric or control without a real outcome;
- loading, empty, error, success and permission states exist where needed;
- mobile hierarchy is intentionally adapted, not just shrunk;
- Light/Dark themes remain coherent;
- keyboard/focus/reduced-motion behavior still works;
- design tokens/components are reused rather than duplicated;
- no horizontal overflow or obvious layout break;
- visible copy is specific and natural in PT-BR.

Return PASS, CONDITIONAL PASS or BLOCK, with only evidence-backed findings.
