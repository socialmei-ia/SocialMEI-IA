---
name: prototype-first
description: Create and evaluate an isolated UI prototype for a substantial new SocialMEI interface before integrating it into the main application.
---

- Keep the prototype isolated from main navigation, real API and production data.
- Use realistic synthetic data and the existing design language.
- Show desktop/mobile behavior and important empty/loading/error states.
- Do not create schema/API changes for a visual prototype.
- Present unresolved UX decisions.
- Integrate only after explicit approval.
