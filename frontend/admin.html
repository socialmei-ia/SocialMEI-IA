Um convite pessoal para começar um negócio separado no SocialMEI.

Convite pronto

Entregue o código apenas à pessoa convidada. Ele não fica salvo neste navegador.
Como funciona
  1. 1Gere o código para o e-mail da pessoa.
  2. 2Ela abre o site e escolhe criar uma conta.
  3. 3Informa o mesmo e-mail e o código recebido.

Válido por três dias. Cada código pode ser usado uma vez. O convite não é enviado por e-mail automaticamente.
